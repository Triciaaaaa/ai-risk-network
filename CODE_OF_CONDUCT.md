# 行为准则 / Code of Conduct

这个项目欢迎对公开数据、文档和工具的具体贡献。参与讨论和评审时，请遵守以下规则。

This project welcomes concrete contributions to its public data, documentation, and tools. Follow these rules in discussions and reviews.

1. 讨论事实和改动，不攻击、贬低或揣测贡献者。<br>Discuss facts and changes without attacking, belittling, or speculating about contributors.
2. 引用公开来源；发现错误时清楚说明证据和建议改法。<br>Cite public sources and explain both the evidence and the proposed correction.
3. 不公开联系方式、私人材料、身份文件或与改动无关的个人信息。<br>Do not publish contact details, private material, identity documents, or irrelevant personal information.
4. 尊重姓名、代词、语言背景和不同经验。<br>Respect names, pronouns, language backgrounds, and differences in experience.
5. 不骚扰、威胁、跟踪、歧视或反复纠缠他人。<br>Do not harass, threaten, stalk, discriminate against, or repeatedly pressure others.
6. 接受维护者对讨论范围、重复内容和失焦争论的整理。<br>Accept repository moderation of scope, duplicates, and off-topic arguments.
7. 看到行为问题时，使用 GitHub 的举报或仓库管理功能，不在公开讨论中扩散私人细节。<br>Use GitHub reporting or repository moderation tools for conduct problems; do not spread private details in public threads.

严重或持续违反这些规则的内容可能被编辑、隐藏或移除，参与权限也可能受到限制。维护决定以保护协作和公开数据质量为准。

Content that seriously or repeatedly breaks these rules may be edited, hidden, or removed, and participation may be limited. Moderation decisions aim to protect collaboration and public-data quality.

本准则参考 [Contributor Covenant](https://www.contributor-covenant.org/)，但使用本项目自己的简短条款。

This code takes the [Contributor Covenant](https://www.contributor-covenant.org/) as a reference but uses its own concise terms.
